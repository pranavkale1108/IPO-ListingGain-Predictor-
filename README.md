## 📌 Project Overview
An end-to-end Machine Learning college mini project designed to analyze and predict listing-day performance of Initial Public Offerings (IPOs) in the Indian equity market (NSE/BSE).

### Key Deliverables / Model Outputs:
1. **Expected Listing Gain (%)**: Regression estimate of listing-day percentage returns (`(listing_price - issue_price) / issue_price * 100`).
2. **Probability of Positive Listing**: Calibrated probability of listing at a premium (`listing_gain_pct > 0`).
3. **Investment Verdict**: Actionable recommendation:
   - `Avoid`: Listing gain < 0% (discount)
   - `Neutral`: Listing gain between 0% and 15%
   - `Apply`: Listing gain > 15%
4. **Peer IPO Comparison**: 5 most similar historical IPOs based on issue size, valuation metrics, and subscription numbers.
5. **IPO Market Mood / Regime**: Hidden regime classification (`Cold` / `Warm` / `Hot`).

## ⚙️ Algorithms & Methodologies

| Component | Technique / Algorithm | Implementation Detail |
| :--- | :--- | :--- |
| **Missing Value Imputation** | Expectation-Maximization (EM) / Gaussian Mixture imputation | Handles missing historical subscription & valuation indicators |
| **Market Mood / Regime Detection** | Hidden Markov Model (HMM) | Custom implementation from scratch in NumPy (Forward algorithm & Viterbi decoding) |
| **Peer Similarity & Clustering** | K-Means & K-Medoids (`scikit-learn-extra`) | Unsupervised grouping and exemplar identification |
| **Listing Gain (%) Prediction** | Linear Regression & Polynomial Regression | Evaluated via RMSE, MAE, R² |
| **Listing Success Classification** | Logistic Regression, SVM, k-NN, AdaBoost / Gradient Boosting | Evaluated via ROC-AUC, Precision, Recall, F1-Score |

## 📜 Core Project Rules

1. **Strict Time-Based Train/Test Split**:
   - Oldest **75%** of IPOs used for training.
   - Newest **25%** of IPOs reserved strictly for testing.
   - **Never** use random splitting (to respect chronological market dynamics).
2. **Data Leakage Prevention**:
   - All imputers, standardizers/scalers, and categorical encoders must be fitted **only on the training split**.
   - Transformations are applied to the test split without refitting.
3. **Artifacts & Visualizations**:
   - All generated charts, calibration curves, and feature importance plots must be saved to `reports/figures/`.
4. **Code Quality**:
   - Modular structure, clear docstrings, reproducible random seeds, and comprehensive inline commentary.

## 🚀 Setup & Execution

### 1. Prerequisites
- Python 3.11+
- Virtual environment tool (`venv` or `conda`)

### 2. Environment Setup
```bash
# Create and activate virtual environment
python -m venv .venv

# Windows PowerShell:
.venv\Scripts\Activate.ps1
# Linux / macOS:
# source .venv/bin/activate

# Install dependencies
pip install --upgrade pip
pip install -r requirements.txt
```

### 3. Generate Synthetic Testing Data (Optional)
```bash
python scripts/make_sample_data.py --samples 300
```
This produces `data/raw/synthetic_ipo_data_WARNING_SYNTHETIC.csv` (and initial `data/raw/ipo_data.csv` if absent).

### 4. Run Data Loader & Cleaning Pipeline
```bash
python src/data_loader.py
```
This validates raw columns, coerces types, standardizes sectors, drops duplicates, sorts chronologically, engineers targets (`listing_gain_pct`, `positive_listing`, `verdict`), and outputs `data/processed/ipo_clean.csv`.
